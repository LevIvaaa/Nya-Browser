# Widevine: защищённое видео

Netflix, Spotify Web, Кинопоиск, Okko и почти любой платный видеосервис
отказываются играть без DRM. За это отвечает Widevine — модуль расшифровки
(CDM) от Google.

## Что уже сделано

Обычный Electron не содержит Widevine вообще. Поэтому проект собирается на
форке **castlabs/electron-releases** — это тот же Electron, плюс компонентный
загрузчик Chromium и API `components`:

```json
"electron": "github:castlabs/electron-releases#v43.2.0+wvcus"
```

Сам CDM в сборку не входит: он скачивается с серверов Google при первом
включении и лежит в `%APPDATA%/Nya Browser/WidevineCdm`. Первая установка
занимает около 40 секунд, дальше — меньше секунды.

Именно из-за этого запроса к Google DRM **выключен по умолчанию**. Браузер,
который в остальном не обращается никуда сам, не должен тихо начинать это
делать. Включается в «Настройки → Система → Защищённое видео».

Загрузка идёт в фоне и не задерживает появление окна. Если включить DRM и сразу
открыть Netflix, страницу может понадобиться обновить.

Проверено: `navigator.requestMediaKeySystemAccess('com.widevine.alpha')`
возвращает доступ и создаёт ключи, CDM версии 4.10.3050.0.

## Что нужно сделать один раз вручную

Для многих сервисов (Netflix — точно) недостаточно рабочего CDM: собранное
приложение должно нести **подпись VMP** от castlabs. Она бесплатная, но требует
аккаунта, а его может создать только человек — на почту приходит код
подтверждения.

```bash
pip install --upgrade castlabs-evs
python -m castlabs_evs.account signup     # один раз; дальше account reauth
```

После этого ничего делать не надо: `npm run dist:installer` сам подпишет сборку
через хук [build/afterPack.cjs](../build/afterPack.cjs). Если `castlabs-evs` не
установлен, сборка не падает — она просто печатает напоминание.

Проверить, что подпись на месте:

```bash
python -m castlabs_evs.vmp verify-pkg dist/win-unpacked
```

## Чего ждать не стоит

Доступен только **L3** — программная защита. Сервисы ограничивают из-за этого
качество: обычно 480p–720p, 4K не будет никогда. Это верно для любого браузера
на Electron и не лечится ни подписью, ни настройками; за 1080p+ сервисы требуют
аппаратный L1, который есть только у Chrome, Edge и Safari с их сертификацией.
